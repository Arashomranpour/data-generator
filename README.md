## ✨ Features

- 🔢 Choose how many profiles to generate (10 - 5000).
- 🌍 Pick one or more locales (`en_US`, `es`).
- 🧩 **Customize** mode - select exactly which profile fields to include.
- 💾 Export as **CSV** or **JSON** with a one-click download link.
- 👀 Live preview of the generated DataFrame.

## 🚀 Getting Started

```bash
git clone https://github.com/Arashomranpour/data-generator.git
cd data-generator
pip install streamlit pandas faker
streamlit run 1.py
```
